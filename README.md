# AntsLife
Een 3D game about ants

## Huidige Status
Dit is een **minimaal prototype** om de grootte van een 10×10×10 kubus te visualiseren.

### Wat je ziet:
- Een **doorzichtige groene kubus** van 10×10×10 units
- Een **Camera3D** op (15, 15, 15) die naar (5, 5, 5) kijkt
- **DirectionalLight3D** voor verlichting

### Hoe te testen:
1. Open `project.godot` in Godot 4.3+
2. Run de `main_3d.tscn` scene (F5)
3. Gebruik je **muis** om de kubus te draaien

## Toekomstige Stappen:
1. 2D cross-section rendering (TileMap)
2. Face switching (1-6 toetsen)
3. Layer depth controls
4. Excavatie mechaniek
